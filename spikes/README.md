# Spikes (G0 hook experiments)

Throwaway experiments for the G0 gate (8 Nov 2026). Nothing here is product code.

- `claude-code/`: Ege's Claude Code hook experiments
- `antigravity/`: B's Antigravity CLI hook experiments

For each experiment, keep a short `NOTES.md` with: the command you ran, the agent version
(`claude --version` / `agy --version`), what you expected, what happened.

Save the JSON that the hook received under `sdguard/tests/fixtures/<agent>/`.
Remove tokens, account ids and any personal data from these files before committing.

Results go into `docs/plan/AJAN_ENTEGRASYON.md` (one table, one row per experiment).
